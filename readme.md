Consigna del sistema

Sistema de Administración Hotelera:  
 Descripción: Desarrollar un sistema completo para mejorar la administración de habitaciones, reservas y limpieza en la cadena de hoteles House Hunter. Este sistema permitirá gestionar reservas, asignar habitaciones y programar tareas de limpieza de manera eficiente.   Enfoque: El enfoque principal estará en la creación de una interfaz intuitiva que permita a los empleados de House Hunter gestionar reservas y habitaciones de manera eficiente. La plataforma proporcionará un estado en tiempo real de la ocupación y generará notificaciones para mejorar la coordinación.
